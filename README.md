# PAD – Specificații tehnice pentru VLC media player

Repository realizat pentru **Lucrarea individuală nr. 1** la disciplina *Planificarea aplicațiilor desktop* (CEITI).

## Despre proiect

Repository-ul conține un mini-document de specificații tehnice pentru aplicația desktop **VLC media player**:

- scopul aplicației și domeniul de aplicare;
- descrierea generală (utilizatori, constrângeri);
- cerințele funcționale (CF-01 – CF-05);
- cerințele non-funcționale (CN-01 – CN-05).

## Structura repository-ului

| Fișier | Conținut |
|--------|----------|
| [`specificatii_vlc.md`](specificatii_vlc.md) | documentul de specificații tehnice |
| `README.md` | descrierea proiectului (acest fișier) |
| `.gitignore` | fișierele pe care Git nu le urmărește |

## Cum se folosește

Documentul se poate citi direct pe GitHub, deschizând fișierul `specificatii_vlc.md`.

Pentru o copie locală:

```bash
git clone https://github.com/NsLeopolld/PAD-Specificatii-VLC.git
cd PAD-Specificatii-VLC
```

## Cum se poate contribui

1. Se creează un branch nou: `git switch -c numele-modificarii`
2. Se fac modificările și commit-urile
3. Se trimite branch-ul pe GitHub: `git push -u origin numele-modificarii`
4. Se deschide un **pull request**, care este verificat înainte de a fi unit cu `main`

Greșelile sau propunerile se pot semnala și prin **Issues**.
